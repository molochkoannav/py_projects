# Домашнее задание: Классы Product и Category

## Описание проекта

Проект реализует базовую структуру для управления категориями и товарами в интернет-магазине.



## Классы

### Product
Класс для представления товара с атрибутами:
- `name` (str) - название товара
- `description` (str) - описание товара
- `price` (float) - цена товара
- `quantity` (int) - количество в наличии
### Smartphone (класс потомок от класса продукт)
дополнительные атрибуты класса:
- `efficiency` (float) - производительность 
- `model` (str) - модель 
- `memory` (int) - объем встроенной памяти
- `color` (str) - цвет 
### LawnGrass (класс потомок от класса продукт)
дополнительные атрибуты класса:
- `country` (str) - страна-производитель
- `germination_period` (str) - срок прорастания
- `color` (str) - цвет 

### Category
Класс для представления категории товаров с атрибутами:
- `name` (str) - название категории
- `description` (str) - описание категории
- `products` (list) - список товаров в категории

Атрибуты класса:
- `total_categories` - общее количество категорий
- `total_products` - общее количество товаров во всех категориях
